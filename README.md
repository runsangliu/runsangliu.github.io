# Runsang Liu — Academic Website

Personal academic website for Runsang Liu, Ph.D. candidate at The Pennsylvania State University.

Website: https://runsangliu.github.io/

## Pages

- `index.html`: profile, research overview, selected publications, news, and education
- `research.html`: research projects and related papers
- `publications.html`: journal articles, manuscripts under review, and conference papers
- `teaching.html`: teaching, mentoring, and service
- `styles.css`: shared styles and responsive layouts
- `assets/runsang-liu.jpg`: profile photograph
- `assets/Runsang_Liu_CV.pdf`: downloadable CV

The website uses plain HTML and CSS. No dependencies or build step are required. Open `index.html` in a browser to preview it locally.

## Publish with GitHub Pages

In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, and save. GitHub Pages will publish subsequent commits automatically.

## Updates

Edit the corresponding HTML file to update content. Publication titles link to their DOI when supplied in the CV. Accepted papers and manuscripts under review are explicitly labeled. Replace the PDF and photograph at the same asset paths to update them without changing page links.

Initial content was transcribed and summarized from the CV supplied in September 2026. Publication dates and statuses follow that CV.
